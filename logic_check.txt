# TÓM TẮT: CÁC LOGIC LỚN TRONG AUTO LATEX

Dựa trên phân tích toàn bộ codebase, project **Auto LaTeX** có **8 logic lớn chính**:

================================================================================
## 1. LaTeX Parsing & Sanitization Engine
================================================================================
📂 Location: src/core/converter.ts

**Chức năng:**
- Parse văn bản tìm các pattern LaTeX: $..$, $$...$$, \[...\], \(...\), environments
- **Xử lý 17+ edge cases** để "chữa lành" LaTeX lỗi:
  • Balance braces thiếu {}
  • Token merging (\muF → \mu F)
  • Vietnamese text auto-wrap trong \text{...}
  • Trailing slashes cleanup
  • Missing \right auto-complete
  • Unicode arrows/symbols conversion
  • \lim formatting với \limits
  • Unescaped %, NBSP, degree symbols
  • Nested environments support

**Input:** Raw text with LaTeX  
**Output:** Sanitized LaTeX string

**Key Functions:**
- sanitizeLaTeX(latex, isBlock)
- balanceBraces()
- sanitizeTrailingSlashes()
- sanitizeTokenMerge()
- sanitizeVietnamese()
- extractNakedEnvironments()

================================================================================
## 2. MathML Rendering Pipeline
================================================================================
📂 Location: src/core/converter.ts + src/utils/parser.ts

**Chức năng:**
- Convert LaTeX → MathML qua **KaTeX**
- Extract và clean MathML từ HTML output
- **Rendering modes**: inline vs block
- Auto-healing error với retry mechanism
- Preview rendering cho chat UI (with streaming support)

**Pipeline:**
```
LaTeX → sanitizeLaTeX() → KaTeX.renderToString() → 
extractAndCleanMathML() → MathML for Word
```

**Key Functions:**
- getKaTeXHtml(latex, isBlock)
- getMathML(latex, isBlock)
- extractAndCleanMathML()
- renderInlineMathPreview()
- autoCloseLatex()

## 3. Word Document Manipulation Engine
================================================================================
📂 Location: src/core/document-editor.ts + src/core/converter.ts

**Chức năng:**
- **Batch conversion** toàn bộ document với chunking (tránh memory bloat)
- **Search & Replace** với Office.js Word API:
  • Short patterns (<250 chars): Direct search
  • Long patterns (>255 chars): expandTo workaround
- **Insert modes**:
  • Replace selection
  • Replace paragraph  
  • Replace search term
  • Replace heading content
  • Insert at cursor / end of document
- **Progress tracking** với cancellation support

**Performance optimizations:**
- Chunking (1 pattern/batch mặc định)
- Bulk sync để giảm round-trips
- Inner chunking cho insertions (10 items/sync)

**Key Functions:**
- runConversion(onlySelection, state)
- DocumentEditor.replaceSelection()
- DocumentEditor.replaceCurrentParagraph()
- DocumentEditor.replaceSearchTerm()
- DocumentEditor.replaceHeadingContent()
- DocumentEditor.getDocumentContext()

## 4. AI Multi-Provider Integration System
================================================================================
📂 Location: src/services/ai.ts

**Chức năng:**
- Hỗ trợ **4 AI providers**: OpenAI, Gemini, DeepSeek, Claude
- **Streaming response** với SSE (Server-Sent Events)
- **Context-aware**: Đọc selected text/paragraph từ Word
- **System prompt engineering** với các rules:
  • XML tags cho Word actions (<insert>, <replace_selection>, etc.)
  • Formula wrapping (<inline_formula>, <block_formula>)
  • Vietnamese/English switching
  • Auto-apply mode instructions
  • Thinking mode support
- **Usage tracking**: API calls, tokens (prompt/cache/completion)
- **CORS proxy** cho Claude (port 3001)

**Architecture:**
```
User → sendChatMessage() → Provider-specific API →
Streaming chunks → Parse & render → Apply to Word
```

**Key Functions:**
- sendChatMessage(history, contextText, appLanguage, documentContext, isThinkingMode, onChunk)

## 5. Chat Message Processing & Rendering Engine
================================================================================
📂 Location: src/taskpane/chat-send.ts + src/utils/parser.ts + src/ui/chat-renderer.ts

  • Parse nested <target> và <content>
  • Auto-apply hoặc show "Apply" buttons
- **Formula rendering** trong chat:

  • KaTeX preview với auto-healing
- **Markdown parsing**: Bold, italic, code, headers, line breaks
- **Incomplete content masking** (cho streaming):
  • Mask incomplete tags
  • Mask unclosed math delimiters
  • Handle partial XML

**Processing flow:**
```
AI Stream → maskIncompleteMath() → processSegments() →
renderFormula() + parseMarkdown() → Display in chat
```
